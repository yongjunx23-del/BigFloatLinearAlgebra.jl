# Round C benchmark report: 2026-08-13

This report records observed behavior; it does not select a machine-wide
default. All timed runs used Julia 1.12.6 on Apple M4/macOS with exact dyadic
fixtures, two warmups, ten timed samples, and a correctness gate before timing.
Unit tests were run separately with bounds checks and deprecation warnings.

## Cholesky workspace

The measured allocation mechanism was the authoritative-triangle `UInt`
identity vector. At n=128, steady-state Native operation allocations changed:

| precision | ordinary bytes | workspace bytes | ordinary median s | workspace median s |
| ---: | ---: | ---: | ---: | ---: |
| 128 | 82,224 | 240 | 0.01455 | 0.01466 |
| 256 | 82,272 | 288 | 0.02078 | 0.02092 |
| 512 | 82,368 | 384 | 0.02780 | 0.02764 |

The first workspace call still grows the buffer: the cold allocations at
n=128 were 82,192/82,240/82,336 bytes. Reuse therefore removes 81,984 bytes
per subsequent factorization without changing its bitwise result. The two
n=128 production cycles containing Cholesky also each removed 81,984 bytes;
their timing changes stayed within run-to-run/IQR noise.

## Frozen SDPX Legacy A/B

Across 60 cells, the median Native/Legacy ratio was 0.9831. By operation:

| workload | mean ratio | maximum ratio | cells over 1.05 |
| --- | ---: | ---: | ---: |
| GEMM | 1.0151 | 1.1236 | 3/12 |
| Cholesky | 1.0024 | 1.0519 | 1/12 |
| Cholesky workspace | 0.9943 | 1.0503 | 1/12 |
| TRSM | 0.9257 | 0.9963 | 0/12 |
| dot | 0.7897 | 0.9875 | 0/12 |

The three GEMM cells above 1.05 were n=8 wrapper-dominated cases. For n>=32,
GEMM mean/max ratios were 0.9914/1.0303; ordinary Cholesky was
1.0100/1.0519, and workspace Cholesky was 1.0022/1.0374. One earlier long
process sweep showed much larger Cholesky ratios, but three fresh-process
p=128,n=128 repeats produced 1.033, 0.993, and 1.025; the final complete rerun
returned to the values above. This is recorded as runtime noise, not discarded.

## Explicit calibration

The p=128/256/512, n=32/128 sweep tested blocks 0/8/16/24/32/48/64 and
requested threads 1/4. On this M4, Level-3 GEMM/SYRK/TRSM representative points
were fastest with explicit four-thread, block-zero dispatch. Cholesky was
single-threaded and its best observed block varied: p=128/256,n=128 favored 24,
while p=512,n=128 favored 0. No universal block default is justified, so the
library keeps caller-selected `KernelConfig` values and performs no autotuning.

## Limitations

- Timing was measured on one Apple M4 machine, not the target cluster.
- Julia 1.10/1.11 are covered by CI configuration but were not run locally for
  this snapshot; local execution used Julia 1.12.6.
- Sizes above 128 were excluded from these complete review runs to bound time
  and memory; the runners retain larger configurable sizes.
